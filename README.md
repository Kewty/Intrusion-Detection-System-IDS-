# 🛡️ Intrusion Detection System (IDS)

Bu proje, ağ trafiğini analiz ederek şüpheli aktiviteleri tespit eden bir **Intrusion Detection System (IDS)** uygulamasıdır. Sistem, belirli imzaları, port aktivitelerini, paket anomalilerini ve potansiyel saldırı örüntülerini tespit etmeyi amaçlar.

---

## 🚀 Özellikler

- 🔍 Gerçek zamanlı ağ trafiği analizi  
- 🧠 İmza tabanlı saldırı tespiti  
- 📡 Port taraması aktivitelerini algılama  
- 🧰 Loglama ve raporlama sistemi  
- ⚙ Kolay yapılandırılabilir kurallar
- 🛑 Şüpheli hareketleri işaretleme (alert sistemi)
- 🔧 Esnek yapı – modüler tasarım
